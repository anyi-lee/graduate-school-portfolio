### PROVE-3D

**Graduation Project · Zero-shot 3D Visual Grounding**

A progressive observation and evidence-based verification framework that determines whether the current multi-view RGB-D observations provide sufficient evidence for a referring expression, and acquires additional views only when needed.

**Focus**<br>
Progressive observation · VLM verification · Multi-view RGB-D · Object-level 2D-to-3D localization
