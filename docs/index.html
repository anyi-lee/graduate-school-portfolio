01 · RESEARCH

PROVE-3D

Progressive Observation and Verification with Evidence for Zero-Shot 3D Visual Grounding

Rather than assuming a fixed set of views is sufficient, PROVE-3D checks whether the current visual evidence supports the target attributes, reference objects and spatial relations in a query. It acquires additional observations only when verification requires them.
